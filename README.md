# Ataullah Portfolio

This is a personal portfolio website for Md Ataullah, showcasing skills, projects, and contact information.

## Features

- Responsive design using [Tailwind CSS](https://tailwindcss.com/)
- Dark mode toggle
- Animated hero section
- Skills and projects showcase
- Contact information

## Usage

1. Clone the repository.
2. Place your profile image as `ataullah.jpg` in the project root.
3. Open `index.html` in your browser.

## Customization

- Update `ataullah.jpg` with your own image.
- Edit `index.html` to change skills, projects, or contact details.
